## 3. N5 冻结设计与正式裁决

### 3.1 设计完整性

### 3.2 H5-A：selective hybrid 没有建立

冻结 gate 可行，score 为 NLA absolute centered cosine，阈值
`0.8361008239052125`。held-out 中 262/400 路由到 NLA：

- coverage：`0.655`；单侧 95% lower：`0.615`；
- primary `G = sum(KL_big-KL_hybrid) / sum(KL_zero)`：`+0.002419`；
- G 单侧 95% lower：`-0.001326`；90% CI：`[-0.001326, +0.006147]`；
- raw paired effect `mean(KL_big-KL_hybrid)`：`+0.032168 nat`；
  95% CI `[-0.026114, +0.091261]`；
- catastrophic regret：`9/400 = 2.25%`；单侧 exact 95% upper：`3.893%`。

两个预注册 gate 失败：G 的单侧下界未大于 0，灾难率上界也未小于 3%。虽然 G 的
90% CI 位于预注册 parity margin `[-.01,+.01]` 内，但 safe-parity 仍要求通过灾难率
门槛。因此唯一正确标签是：

**`H5-A: NO SELECTIVE CLAIM`**。

不能写成 selective improvement、safe parity，也不能用 centered cosine、corpus subgroup
或事后阈值替换失败的 KL-at-position 主终点。

### 3.3 H5-B：第三段 channel 强复制

所有 400 个 explanation 都满足三段结构。冻结 paragraph-channel 指标给出：

- `G_p3_p12 = sum(KL_p12-KL_p3)/sum(KL_zero) = +0.179490`；
- 95% CI：`[+0.146504,+0.215996]`；
- raw `KL_p12-KL_p3` mean：`+2.386608 nat`；
- sign count：326 positive / 74 negative；
- full original aggregate recovery `R_orig = 0.964506`；
- p3-only aggregate recovery `R_p3 = 0.952928`；
- retention `T=R_p3/R_orig = 0.987996`；单侧 95% lower `0.983015`。

两项预注册条件都通过，因此正式标签是：

**`H5-B: CHANNEL REPLICATED`**。

这是对 N4 中“第三段比前两段更有因果价值”的全新 cohort confirmatory replication，
但它不挽救 H5-A，也不等价于证明第三段是人类可读、细节忠实或具有唯一语义解释。

内容很重要；不能只把结果概括成抽象语义通道。

## 5. 当前最稳妥的科学结论

1. **原始 cosine 会被 residual-stream 公共方向严重抬高。** 去均值、检索与 causal KL
   比未中心化 cosine 更有判别力。
2. **NLA 文本通道不是均匀传输三段信息。** 第三段 next-token-candidate channel 在
   N4 后又于 N5 held-out 上预注册复制，并保留约 98.8% 的 full-text aggregate causal
   recovery。
3. **可读候选通道与可靠替代品不是同一件事。** 当前 centered-cosine gate 无法把 NLA
   的少数灾难性失败控制到预注册安全线内，selective NLA + SAE-big 未建立。
4. **closed-loop 可重建不等于人类解释忠实。** 既往错误具体指称、paraphrase sensitivity、
   弱 human/base-judge 对齐和 quote stripping 的大幅退化，都要求把“语言瓶颈”与
   “忠实可解释性”拆开报告。
5. **SAE 与 NLA 的失败模式可能互补，但互补性尚未转化为可部署的 frozen router。**
   这仍是设计线索，不是已证实的性能主张。

## 9. 下一步研究路线

### 9.1 论文主线应立即收敛

现在不需要再做实验才能开始写一篇 scope 清楚的方法与机制论文。当前最强、最安全的主张是：

> 对 Gemma-3-12B-IT L32 `resid_post`，NLA 是一个具有显著因果效用的自然语言
> predictive-state code；重建信号集中于包含 quoted continuation candidates 的第三段。
> 这尚不等价于 proposition-level 忠实解释、优于 SAE-big 的 causal codec，或可靠的

论文应同时报告一个 confirmatory positive 和一个 confirmatory negative：

- positive：N5 H5-B 在 400 个独立 held-out groups 上确认 candidate-bearing p3 是
  near-sufficient、causally dominant channel；
- negative：N5 H5-A 否定当前单变量 centered-cosine router 的 selective improvement
  与 safe-parity claim。

立即可在 CPU/人工侧完成：建立逐项 claim table，标注 `confirmatory / exploratory /
post hoc / failed / not testable`；起草 methods、N4/N5 results、limitations 与 artifact
appendix。不要等下一次 GPU 实验才开始写作。

### 9.2 最有信息增益的下一实验：matched candidate-content substitution

N5 已证明删掉 p3 quoted spans 会使 aggregate recovery 从 `0.95293` 降至 `0.40228`，
但尚未区分两种解释：

1. 样本自身的 candidate identity/content 在传递 predictive state；
2. AR 只依赖 candidate-list 的格式、lexical density 或熟悉表述。

因此推荐把下一项新的 confirmatory experiment 暂称 **N6：matched candidate-content
causal specificity**。核心干预不是再做一次 p3-vs-p12，而是把每个样本 p3 中的 quoted
candidates 替换成来自另一 held-out 样本、在 language/script、候选数和长度上匹配的错误
candidates，同时保持引号外文本 byte-identical。

建议冻结条件：

- 全新 400 independent content groups（Pile 300 / XNLI 100），embargo N4/N5 的文档、
  shingles 和 XNLI premise units；
- cohort、模型 manifest、parser、donor assignment 和分析脚本在任何 model forward 前
  hash-lock；
- deterministic one-to-one donor derangement，不使用 logits、KL、cosine 或人工质量判断选 donor；
- conditions：`orig`、`p3_true`、`p3_cross_matched`、`quote_strip_p3`、`p12`、
  `sae_big`、`identity`、`zero`；
- primary causal metric 继续使用 patched-position `KL(clean || patched)` 与
  ratio-of-sums recovery；所有 400 groups ITT；
- 50,000 次 Pile/XNLI stratified shared bootstrap，预先冻结 seed；
- 同时要求：true p3 优于 cross-matched p3、该差异占 true-vs-strip quoted-content
  gain 的多数、以及 p3 对 full text 的 recovery retention 单侧下界仍大于 0.90。

该实验预计约 2–4 小时 CPU 设计/审计和 1–1.5 A800 GPU-hours。它不是 N5 retry，必须先
形成独立预注册并由用户确认后才能开机执行。若实验通过，才能把 headline 从
“candidate-bearing format/channel”加强为“sample-specific candidate content”；若失败，
则必须把机制解释降级为格式、词汇类别或 generic candidate-list familiarity。

### 9.3 第二优先：CPU-only failure-tail forensic audit

在开 GPU 前，先把 N4/N5 当作**纯 discovery 数据**检查 NLA catastrophe 与 router 失败模式。
只用 causal outcome 发生前可获得的变量，例如 centered cosine、activation norm、base
next-token entropy、p3 长度/quoted count、NLA–SAE disagreement 和 parser anomaly；以
`KL_hybrid-KL_big > 1 nat` 为固定 tail label，做 grouped、leave-source-out 的 AUPRC、
calibration 与 coverage-risk 分析。

目的不是事后宣布新 router 成功，而是判断这条线是否值得一个全新 held-out confirmatory
cohort。若候选 predictor 在 source folds 间不稳定，应关闭 routing 线，不再扫阈值；若稳定，
也只能据此形成下一份预注册，N4/N5 不能被重新包装成 confirmation。

### 9.4 第三优先：capacity-matched rate–distortion operating curve

若论文要比较 NLA 与 SAE 的信息效率，必须补 matched budget：

- SAE：active-index combinatorial cost + 冻结的 2/4/8/16-bit amplitude quantization；
- NLA：UTF-8 bytes 与独立冻结语言模型下的 cross-entropy bits；
- distortion primary：aggregate causal KL recovery；centered geometry/retrieval secondary；
- 单独报告 representation bits、model calls、latency 和生成成本。

在现有 checkpoint 上扫 top-k/quantization 与 p3 truncation/candidate count，只能称
**post-training operating curve**，不能称完整 rate–distortion frontier；真正 frontier
要求不同 bottleneck rates 下重新训练模型。

### 9.5 暂不优先的路线

- 不应自动重启 selective-router N6，也不应继续扫 centered-cosine threshold。
- 跨层或第二模型 replication 对最终顶会外推很重要，但应放在机制明确后；否则只是把
