# NLA（Natural Language Autoencoders）本机运行指南 — Qwen2.5-7B（AV / AR）

本文档面向**本机已经配置完成**的环境，告诉你如何**自己一步步把项目跑通**，以及如何**更换不同的 prompt 做不同的 AV 重建**。

---

## 0. 这个项目在做什么（30 秒理解）

NLA 是一对微调后的语言模型，把一个 LLM 残差流（residual stream）里的**激活向量 ↔ 自然语言**互相映射：

| 方向 | 名称 | 机制 |
| --- | --- | --- |
| 向量 → 文本 | **AV**（activation verbalizer，激活描述器） | 把激活向量当作一个 token embedding 注入到固定 prompt 里，自回归生成对该向量语义的描述 |
| 文本 → 向量 | **AR**（activation reconstructor，激活重建器） | 用截断的 K+1 层 LM + Linear(d,d) 头，从 AV 的描述文本里重建出向量 |

两个向量都做 L2 归一化后比较，`MSE = 2(1 − cos)`。**cos 越接近 1、mse_nrm 越接近 0，说明 AV 的文字描述越准确地保留了原向量的方向信息。**

> 本机用的是 Qwen2.5-7B-Instruct 家族，提取层 = **第 20 层**（decoder block 20），`d_model = 3584`。

## 2. 完整跑通流程（三步）

> 所有命令都在项目根目录 `/root/autodl-tmp/natural_language_autoencoders` 下执行。

### 第 1 步：启动 AV 服务（开一个终端，保持运行）

```bash
cd /root/autodl-tmp/natural_language_autoencoders
MEM_FRACTION=0.6 bash demo/launch_av_server.sh
```

- `--disable-radix-cache` 是 **input_embeds 注入向量的必需项**（脚本里已默认带上）。
- `MEM_FRACTION=0.6` 表示服务只占用约 60% 显存（~58 GB），把剩余显存留给同进程里要加载的 AR（~10.5 GB）。本机显存大，0.6 很宽裕。
- 看到这一行就代表就绪：
  ```
  The server is fired up and ready to roll!
  ```
- 服务默认监听 `http://localhost:30000`。

### 第 2 步：提取激活向量，生成 parquet（另开一个终端）

```bash
cd /root/autodl-tmp/natural_language_autoencoders
python demo/make_parquet.py \
    --base-model /root/autodl-tmp/models/Qwen2.5-7B-Instruct \
    --layer-index 20 \
    --text "The Eiffel Tower, completed in 1889, stands on the Champ de Mars in Paris." \
    --chat \
    --out /root/autodl-tmp/demo.parquet
```

它会把这段文本的每个 token 在第 20 层的激活向量写进 `demo.parquet`（外加 `token_str` / `position` / `raw_norm` 等诊断列）。运行完会打印每个 token，方便你判断 `--skip-first` 要跳过多少。

### 第 3 步：跑完整 round-trip（AV 描述 + AR 重建 + 打分）

```bash
cd /root/autodl-tmp/natural_language_autoencoders
python demo/roundtrip.py \
    --av  /root/autodl-tmp/models/nla-qwen-av \
    --ar  /root/autodl-tmp/models/nla-qwen-ar \
    --parquet /root/autodl-tmp/demo.parquet \
    --sglang-url http://localhost:30000 \
    --skip-first 24 --temperature 0 --max-new-tokens 200 \
    --n 6 \
    --out /root/autodl-tmp/demo_results.json
```

**本机实测输出（节选）**，证明已跑通：

```
[ 26] token='iff'  ||v||=133.9  mse_nrm=0.137  cos=0.932
    ... "The Eiff" strongly implies a famous landmark name, most likely "Eiffel Tower" ...
[ 28] token=' Tower'  ||v||=132.7  mse_nrm=0.096  cos=0.952
    ... "The Eiffel Tower" ... is located in Paris / has a height of ...
==========================================================================================
SUMMARY  n=6  mean cos=0.940  mean mse_nrm=0.120  (cos>=0.7 ~ good, ~0.0 ~ random)
==========================================================================================
```

AV 仅凭激活向量就准确还原出 “Eiffel Tower” 的语义，AR 重建的方向一致性 **cos≈0.94**（很好）。

## 3. ⭐ 如何更换不同的 prompt 做不同的 AV 重建

这里的“prompt”指的是**你想要被描述的那段输入文本**。流程是：

> 换一句话（`--text`） → 重新生成 parquet → 再跑一次 roundtrip。

AV 服务**不用重启**，只需重复第 2、3 步即可。

### 例 A：换成完全不同主题的句子

```bash
# 重新提取激活
python demo/make_parquet.py \
    --base-model /root/autodl-tmp/models/Qwen2.5-7B-Instruct \
    --layer-index 20 \
    --text "Photosynthesis converts carbon dioxide and water into glucose using sunlight." \
    --chat \
    --out /root/autodl-tmp/bio.parquet

# 再跑 roundtrip（注意换成新的 parquet）
python demo/roundtrip.py \
    --av /root/autodl-tmp/models/nla-qwen-av \
    --ar /root/autodl-tmp/models/nla-qwen-ar \
    --parquet /root/autodl-tmp/bio.parquet \
    --sglang-url http://localhost:30000 \
    --skip-first 24 --temperature 0 --n 8 \
    --out /root/autodl-tmp/bio_results.json
```

### 例 B：换中文 / 任意语言

```bash
python demo/make_parquet.py \
    --base-model /root/autodl-tmp/models/Qwen2.5-7B-Instruct \
    --layer-index 20 \
    --text "故宫位于北京中轴线的中心，是明清两代的皇家宫殿。" \
    --chat \
    --out /root/autodl-tmp/gugong.parquet

python demo/roundtrip.py \
    --av /root/autodl-tmp/models/nla-qwen-av \
    --ar /root/autodl-tmp/models/nla-qwen-ar \
    --parquet /root/autodl-tmp/gugong.parquet \
    --sglang-url http://localhost:30000 \
    --skip-first 24 --temperature 0 --n 8
```

### 关于 `--skip-first`（重要）

- 加了 `--chat` 时，文本会被套进 Qwen 的对话模板，**前面会有一段固定的 system / 角色前缀**（约 24 个 token）。这些前缀 token 的激活没有语义价值，所以 `--skip-first 24` 用来跳过它们，直接看你真正输入的内容。
- 如果你**不加 `--chat`**（把文本当作纯语料字符串），前缀只有 1 个特殊 token，这时用 `--skip-first 1` 即可。
- 想确认到底跳几个：看第 2 步 `make_parquet.py` 打印出的 token 列表，数一下你输入的第一个词在第几位。

### 只想看某几个 token / 全部 token

- `--n 6`：跳过前缀后，只处理 6 个位置（调试时快）。
- `--n 0`（或不写）：处理 `--skip-first` 之后的**所有** token。

### 其他常用可调参数

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| `--text` | **要被描述/重建的 prompt 文本**（核心，换它就换重建对象） | 任意句子 |
| `--chat` | 是否套对话模板 | 想模拟真实对话激活就加；纯语料就不加 |
| `--layer-index` | 提取第几层激活 | Qwen NLA 固定 **20**，不要改，否则和检查点不匹配 |
| `--temperature` | AV 生成温度 | `0` = 贪心，结果可复现；想看多样描述可设 `0.7` |
| `--max-new-tokens` | AV 描述最大长度 | 默认 200，够用 |
| `--skip-first` | 跳过开头几个 token | `--chat` 时 ≈24；非 chat 时 1 |
| `--n` | 处理多少个位置 | 调试用小值，全量用 0 |
| `--out` | 结果存 JSON 路径 | 建议每个 prompt 用不同文件名 |

## 4. 只要 AV（不需要 AR 评分）时的更轻量用法

项目根目录有一个自包含的单文件客户端 `nla_inference.py`，只让 AV 描述向量、不做重建打分：

```bash
# 服务照常开着的前提下：
python nla_inference.py /root/autodl-tmp/models/nla-qwen-av \
    --sglang-url http://localhost:30000 \
    --parquet /root/autodl-tmp/demo.parquet
```

不带 `--parquet` 则对一个随机单位向量做冒烟测试。

## 5. 收尾 / 故障排查

- **关闭 AV 服务**：到运行 `launch_av_server.sh` 的终端按 `Ctrl+C`；或 `pkill -f sglang.launch_server`。
- **`Connection refused` / 连不上 30000**：AV 服务没起来或还在加载，等到出现 “fired up and ready to roll” 再跑 roundtrip。
- **`AssertionError: duplicate template name`（import sglang/torch 时）**：见第 1 节的 torch 残留文件说明，删除 `torch/_inductor/kernel/` 下旧版同名 .py。
- **显存不够**：调低 `MEM_FRACTION`（如 0.5），或减小 `CONTEXT_LENGTH`。
- **AV 输出变成乱码/中文乱蹦**：通常是 scale 因子不对——本机 `nla_meta.yaml` 已正确（`injection_scale=150.0`），保持用脚本默认即可。更细的排查见 `docs/inference.md`。

---

## 6. 一句话总结

> 服务起一次（第 1 步），之后**改 `--text` → 重生成 parquet（第 2 步）→ 跑 roundtrip（第 3 步）**，就能对任意 prompt 做 AV 描述 + AR 重建评分。`cos` 越高代表 AV 的自然语言解释越忠实地刻画了那段文本在模型内部的激活方向。
